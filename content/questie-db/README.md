## Forever confidence

Each Forever-new quest gets:

- `foreverEvidence`: any of `traces` (QuestieTrace player traces aggregated from Forever clients),
  `wowheadForever` (generated delta-base row citing a `wowhead.com/forever/quest=` page), `authoredFix`
  (hand-authored Forever fix).
- `foreverConfidence`: **high** when the id is ≥ 90000 (Forever's own range) or has `traces` / `wowheadForever`
  evidence; **low** otherwise.

This snapshot has 1215 Forever-new Horde/neutral quests (1211 high, 4 low). Per-zone counts are
`foreverQuestsByZone` and `foreverQuestsByZoneConfidence` in `meta.json` (Zephras Isle: 121).
